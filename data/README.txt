E-COMMERCE DATA ANALYTICS DATASET

Files:
1. customers.csv - 1,000 customers
2. products.csv - 240 products
3. orders.csv - 10,000 orders
4. order_items.csv - order line items
5. ecommerce_sales_master.csv - merged analytical dataset

Recommended project workflow:
Python/Pandas -> Cleaning -> EDA -> SQL -> Power BI -> Business Insights -> ML

Key relationships:
customers.customer_id = orders.customer_id
orders.order_id = order_items.order_id
products.product_id = order_items.product_id

Revenue = price * quantity * (1 - discount)
Cost = cost_price * quantity
Profit = revenue - cost


# Ecommerce Data Analytics — Data Folder

This folder contains the data-related resources used in the Ecommerce Data Analytics project.

## Contents

- **Analysis-ready dataset:** Prepared data used for business analysis and visualizations.
- **Visualization charts:** PNG charts generated by Python scripts.
- **Power BI dashboard:** `Ecommerce_Sales_Dashboard.pbix` — kept local until reviewed for sensitive data.

## Data Privacy

CSV datasets and Power BI reports are excluded from public Git tracking until they have been reviewed for sensitive information.

## Note

The project scripts are available in the `python` folder. The analysis-ready data is used to generate business metrics, category analysis, customer analysis, time-series analysis, and visualizations.
